The released reader preserves the document design

Each obligation below is pass/fail against the owner-selected lab composition and source facts, plus the actual incremental-design consumer. Internal module and schema homes belong in Program Design.

Protected meaning

Keep both decision columns and selected verification procedure presentation; do not restore the removed Reading experiment/Follow the rule selector. Existing immutable author facts stay authored facts. Ordinary page sections (entities, capability purposes, binding/trace tables) can sit beside the browser without artificial record kinds. Record-body Markdown is supported through the established island contract; no bespoke Markdown engine is added.
