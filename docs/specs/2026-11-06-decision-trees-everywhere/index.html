Decision trees everywhere

The fix: sunstack treats every Jev judgment the same way. Choosing which skills a rule reads, and deciding whether a rule warns, both become a small tree of questions that each ask one thing. Examples are written in the rule files, and sunstack hands them to Jev with the text it is judging. A rule proves itself on real cases inside sunstack. Then agents just run sunstack lint and get short warnings that point at files and lines.

  1. The five parts: confirm or correct how I grouped what you asked for, on the Requirements page.
  2. Descriptions that name products (your U16 row 11): this needs the description rule, which is one of the eight judged rules this design leaves off. Recommended: rebuild it next, the same way, as the first rule after this. That leaves your row 11 uncovered until then. If you want it in this round instead, say so, and it joins as a third rebuilt rule with its own cases.
