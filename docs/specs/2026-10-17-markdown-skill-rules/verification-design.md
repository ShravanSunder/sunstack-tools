**Owner-facing summary.** This is planned proof; nothing has run yet. Every row is planned to run locally, with no paid calls. Print shows the assembled question, while the full runtime request is inspected through the prepared-request output. The spike's five-skill baseline is a feasibility oracle with known limits (setext headings, quoted prose), not a universal one. Two new lasting journeys get added to `verify-sunstack-rule`: "assemble and print rule sources", and "check refusals". The decision matrix, real markers in real skills, and verdict quality are Sunstack's work and stay outside this proof.
