# Evidence selection: verification design

How each requirement in [Requirements](requirements.md) U13–U17 will be shown to hold, against the [Specification](specification.md)'s proof obligations V13–V21 and the [Program Design](program-design.md)'s proof seams. It adds to the [2026-10-29 verification design](../2026-10-29-skill-rules-evidence-and-decisions/verification-design.md), whose rows stay in force. Nothing here has been observed yet.

The project's verification skill is `.agents/skills/verify-sunstack-rule/`. Two of its lasting journeys reach these entries already and gain cases: "rulebook lint" (`references/rulebook-lint.md`, `scripts/verify/sunstack-rule/rulebook-lint.ts`), which drives the binary over a fixture repository against a scripted loopback decision endpoint and captures exact request bodies, and "rulebook check refusals" (`references/rulebook-check-refusals.md`, `scripts/verify/sunstack-rule/rulebook-check-refusals.ts`). Two observations are new and temporary: a comparison of the 0.2.0 release binary with this build on the same answers, and one live run over every skill.

## Shared observation: "rulebook lint", selection cases

One fixture repository gains a selected `workflow_section` kind, a contained `step` kind, a `load` kind whose `step` field reads `kind: step`, and copies of practices-research and presentation-tui `SKILL.md` plus a file with no numbered list. The loopback answers each selection question by candidate key from a script. It serves U13 (request shape, outcomes, split, `--evidence`, `--since`, sameness), U14 (containment, kind-based fields, ordering), U15 (report fields and counts) and U16 (failures and budget). The existing cases from 2026-10-29 still run unchanged.

## What stays unverified

The model's judgment of which sections are workflows (the kit measures it against labelled sections), the static Linux release artifact with selection (the hosted S3 route runs at release), sending several rules' questions in one request (not built), and skill shapes the fixtures and sunstack main don't contain.
