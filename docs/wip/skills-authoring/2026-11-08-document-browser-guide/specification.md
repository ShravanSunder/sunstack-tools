# Guide obligations and transferable rules

## Obligations

G1: The existing guide routes an author who needs coordinated prepared document browsers to one complete reference and consumes its concrete authored result.
G2: The reference documents the implemented public tags, required stable IDs, optional labels, canonical owner pages, metadata/body references, seven record kinds, forward relationships and explicit parts.
G3: The reference carries a complete valid worked collection whose invented content differs from the private evaluation input.
G4: The reference teaches prepare/reprepare/check ordering, local Markdown source retention, generated carriers and write effects through the matching documented CLI.
G5: The reference teaches partial later stages, zero call paths, absent observations and multiple supplied outcomes without fabricating facts or claiming a source call path was measured.
G6: The reference preserves rich source forms, links and disclosure state and uses the library's existing styles/controls.
G7: Existing routine author validation, private-runtime trust choice and source-versus-browser proof boundary remain unchanged.
G8: Authored examples and reference links pass actual matching package/CLI checks and the independent named author composition is evaluated against facts fixed before guide writing.

## Standards and transfer

S1: Keep supplied meaning once and let derived views read it.
Transfer A: a policy-design collection shares one rule across two needs without copying its prose; transfer B: an incident record duplicated into a hand-written outcome JSON is rejected because its meanings can drift; passes both.
S2: Use the implemented tool contract rather than recreating presentation behavior.
Transfer A: a plain HTML training document uses the supplied component binding; transfer B: a hand-rolled Svelte picker in a framework-free reader is rejected; passes both.
S3: An absent observation remains absent and distinct supplied results keep their identities.
Transfer A: an unfinished design shows unwritten stages without fake checks; transfer B: two supplied contradictory runs are not collapsed into a green overall result; passes both.
S4: Prepare source-dependent readers again when their source changes.
Transfer A: a local Markdown body edit becomes a new prepared reader; transfer B: editing only a generated snapshot while the source remains old is rejected; passes both.
S5: Claim only the validation actually performed.
Transfer A: a Markdown reference example is called statically valid after CLI check; transfer B: a fresh Julia author is not called generally reliable from one successful artifact; passes both.
Demistify names/commands are the adopted tool's supported API, not generic instructions for every repository.
