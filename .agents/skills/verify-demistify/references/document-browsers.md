2. Exercise needs-only, partial later records and complete zero-stack inputs without fabricating frames. An empty call view reports that no call paths are supplied. Broken or wrong-kind declared edges fail preparation, preserving prior output bytes. Repeat unchanged preparation to confirm one carrier and stable output; extra home/plan HTML stays authored. 3. For every rendered need link, compare its href to the prepared need’s actual page plus its bodyRef fragment. Use an input where record ID differs from body ID. Follow the link to the visible owner passage; a target inside a template, hidden container or missing element fails. Check both a mapped frame’s need link and the unmapped-need action. Preserve the exact source caption: this component does not turn it into a guessed file URL.
4. Drive stack picking, frame selection, supporting-call expansion, cold/current stack/call addresses, history where implemented and the unmapped-need state. Check actual selected identities, visible content and URL together. Press Up/Down and Left/Right through their supported selections. With focus in the actual picker input, those keys must keep text-entry behavior and not switch a call; Escape closes the picker and returns focus. A source handler is not keyboard proof. 5. Change an out-of-root record body or relationship, prepare and reload: Comments revision changes. Unchanged preparation keeps the revision. Select a frame, disconnect/reconnect the reader and check selection, focus and source revision remain valid. With unprepared, invalid or version-mismatched carriers, the reader gives its diagnostic while Comments still registers and resolves the failed source. A pure fingerprint test does not establish registration timing.
6. Read actual source bodies in their owner pages, including supplied tables, local/external links, inline code, Markdown, diagrams and disclosure states. Keep proposed procedures separate from supplied observations; missing results are not passing observations. Check source preservation against the independent input and retain original evidence separately when a current example is migrated.
