## Source path and current assertion limits

Runtime [registration](../../../../packages/demistify/src/runtime.ts) upgrades the three public elements. [Choice](../../../../packages/demistify/src/islands/choice.ts) retains inert authored source, renders title/body through the shared Markdown owner, makes native inputs authoritative and emits `choice-change`. [Comments](../../../../packages/demistify/src/islands/comments.ts) binds the original explicit document tuple, reads current choices, scopes target controls and owns listener/observer/highlight cleanup. Its [view](../../../../packages/demistify/src/islands/comments-view.ts) sends composition to the store, opens the native drawer, formats the current review for clipboard/manual copy and downloads the current JSON envelope.

[Anchors](../../../../packages/demistify/src/core/review-anchors.ts) project original text, capture the actual browser quote and resolve exact source/context or unavailable. [The store](../../../../packages/demistify/src/core/comment-store.ts) validates the comments-only snapshot, persists the explicit tuple and preserves invalid raw bytes; [the model](../../../../packages/demistify/src/core/review-model.ts) owns schemas and review formatting. [Drawer](../../../../packages/demistify/src/islands/drawer.ts) owns replacement at both widths and returns scoped close; [inspector](../../../../packages/demistify/src/islands/inspector.ts) restores an active drawer before fullscreen, while [copy reconstruction](../../../../packages/demistify/src/islands/inspection-copy.ts) separates copied and live originals. [Feature styles](../../../../packages/demistify/src/styles/choice-comments.css) use shared geometry/palette/motion owners. These are source relationships; they do not establish runtime success.
