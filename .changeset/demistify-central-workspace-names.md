Typed delivery uses the Central workspace's words. A deliverable's `dependsOn` is now `blockedBy`, and `builder` is now `implementer`, with optional `verifier` and `reviewer` aliases that the check validates against the identity file the same way. Scoped `implementationTasks` are now `issues`, each `{ id, title }` with a required title, and `implementation.completedTasks` is now `implementation.closedIssues`. A project in `initiative.ts` may name the one workspace `area` it belongs to; the initiative view and `initiative status` carry it. Delivery progress, the initiative overview and the brief show the roles, "Blocked by" and each issue's title.

This experimental v1 update renames the fields with no fallback: an old name fails the check with a message naming its replacement. Rename the fields in each deliverable module and `design-delivery.ts`, give each issue a title, and regenerate the design SDK and views with the matching CLI. `deliverables.generated.json` is now version 2 and `initiative.generated.json` version 3, so pages need views regenerated by this release.
