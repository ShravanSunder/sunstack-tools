Check a Demistify project without writing generated files by default. Add `--write` to existing project check automation that refreshes project and milestone views. After updating the CLI, run `demistify design types <milestone>` for each registered milestone to refresh the generated SDK and types.

Projects can link to declared reviewed passages within the site root. The project overview shows open owner questions, milestones, delivery state and builder assignments. The installed CLI can also check rendered pages at desktop and phone widths using a local Playwright installation.
