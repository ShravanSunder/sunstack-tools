Teach the authoring guide's content reference to keep the meaning of rich content carried onto a page along with its text: supported attributes and states such as status, icon and a disclosure's initial `open` state. A carried form or state changes only when the request or the reader's task calls for it, keeping its meaning with a brief adjacent note; an unsupported value stays as visible text with the same note. Structural or literal whitespace is kept. Each supplied ID stays on the element the source gave it to, with no copied or moved IDs and every ID unique, including `template` content. Name each component once in its own title while surrounding summaries and headings name the larger question.
