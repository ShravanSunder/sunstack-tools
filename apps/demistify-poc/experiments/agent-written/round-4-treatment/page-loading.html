1. Browser parses the explainer HTML. 2. It fetches theme.css (blocking) and runtime.js (module, deferred) in parallel. 3. First paint happens with fallback fonts once theme.css arrives. 4. Text fonts download and swap in. 5. The runtime registers elements and renders islands.

## Measurements
Transferred size fell on all three pages. The main page's first contentful paint went from 324 ms to 152 ms. The diagram page went from 949 KiB to 650 KiB.
## Arrows between islands Three options were considered. The chosen one keeps connected islands in rows or columns. A flow container keeps connected islands in rows or columns and routes arrows through the gaps. Free-form whiteboard arrows stay simple, and the issues panel flags crossings. Any arrow finds a path around boxes in any layout. Needs a lazy routing engine of a few hundred KB, and gives less predictable results. Connected structure belongs in Mermaid.
