The authored Luna page stays 4,924 bytes / 1,099 source tokens. The generated prepared page is 13,920 bytes and uses internal prepared markup; it is not new authoring vocabulary or a smaller source document. This fixed experiment does not establish a general compiler, production default or universal performance gain. The current full explorer was ready in 79–90 ms fresh / 32–40 ms on reload. Eight real selections took 3.7–9.9 ms synchronously and 13.7–32.2 ms over the library's two-frame settlement measure. These are bounded local observations, not field INP or WAN rendering timings. Real 390×844 child contexts showed no outer horizontal overflow for the explorer, source review or prepared review. Narrow inspection retained nine main code rows beside its nine copied rows. Keyboard and visible pointer closing preserved the original; the automation locator's tall-frame autoscroll needed a direct visible pointer check. Public HTTP requests separately measured gzip CSS 12,514 bytes, runtime 23,945, optional engine 506,562 and graph JSON 96,500. Actual native Worker ready and rendered-SVG messages were observed in a separate diagnostic. No new deployment or library default changed. The frozen reference still matches all 100 node/mode compositions and preserves 1,870 long text values, 714 source anchors and 350 edge identities.
