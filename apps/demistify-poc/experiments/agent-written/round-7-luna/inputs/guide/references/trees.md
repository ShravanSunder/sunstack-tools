# Trees

```html
<ex-tree title="08:18 status" icon="rocket">
- planned: Ready to merge — none
- [#212 Idempotent refunds](#pr-212)
  - done: Build and 412 unit tests pass
  - question: Needs replay proof, 08:40–09:00
- [ ] Rounding decision
- [x] Load test booked
</ex-tree>
```

A leading tone word (`done:`, `risk:`) gives a node its icon and colour; `[x]`/`[ ]` make checklist items. `[text](#id)` jumps to that island when clicked. Branches collapse. `layout="map"` draws the same list as a left-to-right mind map (an outline on phones).
