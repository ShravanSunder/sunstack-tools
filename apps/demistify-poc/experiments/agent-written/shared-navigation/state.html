Where delivery state lives

The execution design lets the object sleep between events because the facts needed by the next event have an owner outside disposable object memory.

Stored custody survives the nap

The custody row is stored before central answers Accepted. A push records its send identity and retry time. Its answer arrives as a separate event and matches the connection and send identity before advancing custody.

The object instance is disposable

A new instance reads storage and socket attachments. It does not depend on an in-memory reply waiter surviving from the sending event.

This is a reading example of the existing central execution design, not a report that the design has shipped or passed verification.
