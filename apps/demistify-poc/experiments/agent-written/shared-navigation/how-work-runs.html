How work runs: today vs the new design

Today, almost every websocket request becomes a job, and a push waits in memory for its answer. The job waits for an alarm, the alarm runs cleanup first, and only then do jobs run, 8 at a time, each holding the object awake until its Router answers. In the new design a request is handled in the event that received it, an answer is its own event, and the object sleeps in between.
