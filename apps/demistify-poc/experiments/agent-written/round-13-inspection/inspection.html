# Inspect islands without losing the page Open the sidebar beside a live island. Its main content stays available. The panel starts from the current view, then its local controls work independently; it is not a synchronized editor. Fullscreen enlarges the original view and returns it on close. ## Interactive composition
- Session lifecycle - Current transport - Stable session - Reconnect - Expire
Why two owners?The session owns work; the transport owns a connection.
A disconnect loses the session.
Reconnect swaps the transport.
