From a call to the need it serves

A source-derived call chain answers who calls whom; a runtime stack answers which invocations are active at an instant. A sequence diagram answers who exchanges messages over time. This nested call model keeps the callers visible and links each mapped call back to its user need.

The calls, source addresses and verification results are illustrative. This page contains no captured runtime stack or timing measurement. Branches are shown inside a frame, rather than invented as additional calls.
